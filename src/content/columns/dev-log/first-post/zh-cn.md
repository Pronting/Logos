## 为什么选择 Astro

在众多静态站点生成器中，Astro 以其独特的岛屿架构脱颖而出。

### 技术选型考虑

1. **性能优先** - Astro 默认零 JS，页面加载极快
2. **框架无关** - 可以使用 React、Vue、Svelte 等任何框架
3. **内容驱动** - 对博客类网站天然友好

### 初始搭建

```bash
npm create astro@latest
```

就这样，博客的旅程开始了。
