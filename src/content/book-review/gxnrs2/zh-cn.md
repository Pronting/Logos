# 前言
这本书的后半段讲述的方面从个体而变到群体，虽是团队管理，但其内说明的论点却适用于广泛的人际交往关系中。下面我分为大概两类去归纳7个习惯中的4个习惯

# 正和游戏
人际交往的结果无非几种：
1. 你赢他输
2. 你输他赢
3. 你输他输
4. 你赢他赢

这些纸上谈兵的道理大家似乎都懂，但实际落地下来却是艰险万分。我很喜欢罗翔老师一句话
>世界上最遥远的距离，不是马里亚纳海沟到珠穆朗玛峰的距离，而是知道与做到的距离。很多时候，你明明知道是对的，但总是做出最错误的决定。

好，那么话题扯远了，以上的人际交往结果无疑是第四种最好，前两种表明了世界是零和游戏资源有限，他拿的多你就拿的少，反之亦然。第三种则是对于个体不成熟的一种具象化体现。

就比如说第三种是什么类的人会进行的游戏呢？通常情况下，这类人拿不到自己想要的结果，付出了一定的沉没成本之后，气不打一处来。随后，又花费时间、精力、金钱，把对方那份的收益给搅糊。这种折了夫人又赔兵的行为，在当时的环境与情绪的烘托下，一切显得如此“合理”

再谈前两类. 诚然，世界的资源是有限的不假，但我们的颗粒度太小，小到几乎我们能接触的资源取之不尽，用之不竭。不必杞人忧天地认为他人的成功就等于我的失败。


了解完双赢的方向论之后，再看另一个概念，叫做“情感账户”。书中说到，在与人交往的过程中会不断往账户储蓄金额亦或是消耗金额。在未来的某些决定上会参照情感账户上的数字。展开来说，所谓情感账户，存储的不是金钱，而是增进人际关系不可或缺的信赖，也就是他人与你相处的那一份安全感，能够增加感情账户的存款的是礼貌、诚实、仁慈与信用

这笔存款需要双方各自经营，各自往里定投，会随着时间产生复利效应。

你的一个微笑、一次小礼物、一次倾听，都能为这笔账户添加一份燃料，让它烧得更久，烧得更旺。一旦停止这份关系的维护，那这笔账户也就会被 “通胀” 所影响，实际的收益不断下滑，基数越大，实际收缩的数额就会越大


以上就是整本书中后半部分的部分内容。泛化地说，他是让我们重视人际关系，并把人际关系的重要性看作了一个账户，需要不断打理、经营与他人的交往，也是要做到利他，而不是做一个精致利己主义者，只有当真正利他了，你的价值才会得到体现，最终的导向还是会利己。所以，利他就是双赢的选择

那具体来说就是要处处为他人着想，想尽一切办法帮助他人，并对他人产生影响；用心经营人际关系，未来的一些重大决定，比如帮你一个大忙，这些都是要看情感账户的数字来选择是否要进行






# 综合提效

先通过一个概念来展开这一章节的论述，权力悖论————讲的就是人们开始因为善良，乐善好施，富有同理心，渐渐的，众归所望，众人把它推到一个很高的位置。这个位置享受的权利，而在日益进行的事项中，这个人逐渐被权力腐化，丢掉了最初的性格与行为，变得傲慢、独断，并带有强烈的优越感，当当权者不再为集体谋福祉的时候，集体就会收回赋予他的权利，最终导致名声扫地


这个悖论也是发生在生活的方方面面，说到根本就是人性。当我们没有触碰到那个高度，是我们能恪守本心，乐善好施，求同存异，可一旦够着的那个位置，我们就想与普通人拉开，让自己和普通人产生对比而来获得优越感。这种集体无意识的特性深化到我们的内心，无法改变，只能通过后天有意识的训练


也就引出了这个章节的说明，综合提效————当我们处于团队并有一定的话语权时，这时候不同的声音才是整个团队中最宝贵的财富。比如一些组织架构严明，有多级的上下级关系，方案讨论、工作汇报都有明确的对象，而多级上下级的权力体系就意味着会出现多位当权者。往往第一线的员工才知道问题的具体细节、解决方案，但碍于当权者的利益，无法说出心中的声音。则导致效率低下，无法用最快的方案推进项目，重则可能导致项目经济损失
反过来再看扁平化管理，除了Leader，所有人的职级都一样，能在团队中发表不同的声音，Leader只需要选择一个综合最好的即可。这种扁平化管理砍掉了无关的权力等级，理论上能防止很多犯错
